  https://github.com/googlefonts/atkinson-hyperlegible-next
  commit 7925f50f649b3813257faf2f4c0b381011f434f1 (the commit google/fonts' METADATA.pb names)

  OFL.txt                                                     -> OFL.txt
(renamed only: brackets in file names don't survive URLs well).

app.css's @font-face rules reference them, so the build gives them hashed names;
root.tsx preloads the upright one. To change the family, swap these files and
the @font-face rules and edit the one --font-sans line in app.css's @theme.
